# GHOST · 시골 마을 술래잡기

일본 시골 마을, 폐광산, 백룸을 배경으로 한 **1인칭 온라인 비대칭 술래잡기**입니다.
술래(6명 이상이면 2명)와 생존자가 겨루며(최대 8명), 브라우저만 있으면 휴대폰과 PC에서 함께 플레이할 수 있습니다.

## 실행

```bash
npm run setup   # backend(ws), frontend(three.js) 의존성 설치
npm start       # http://localhost:3000 (PORT 환경변수로 변경)
npm test        # 백엔드 규칙/방/서버 테스트
```

친구와 플레이하려면 서버를 외부에서 접속 가능한 곳(클라우드 서버, 또는 ngrok 같은 터널)에 띄우고 그 주소를 공유하면 됩니다.

## 구조 (백엔드 / 프론트엔드 분리)

```
backend/   Node.js 서버 (권한 서버: 모든 판정은 서버가 결정)
  src/server.js   HTTP + WebSocket(/ws), 프론트엔드 정적 파일 제공
  src/rooms.js    방 만들기 / 방 목록·비공개 설정 / 4자리 코드 참가 / 강퇴 / 방장 위임 / 시작
  src/game.js     게임 시뮬레이션: 이동 검증, 스태미나, 방망이, 덫, 발전기, 탈출, 승패
  src/mapgen.js   시드 기반 마을 생성, 발전기·시작 위치 배치(도달 가능한 곳만)
  test/           node:test 테스트
frontend/  브라우저 클라이언트 (빌드 단계 없음, three.js)
  index.html, css/style.css
  js/main.js      메인 → 시작하기(방 만들기/방 목록/코드로 참가) → 대기실 → 게임 → 결과
  js/net.js       WebSocket 클라이언트(자동 재연결)
  js/settings.js  화면 감도·효과음 설정 저장
  js/game/voice.js 음성 채팅(WebRTC, 서버가 정한 거리별 크기 적용)
  js/game/        렌더링(world, models, textures), 입력(input), 게임 세션(session), 효과음(audio)
shared/    양쪽이 함께 쓰는 규칙 상수(constants.js)와 충돌 처리(collision.js)
```

프론트엔드를 다른 곳(정적 호스팅)에 따로 올릴 때는 `frontend/js/config.js`의 `GHOST_SERVER_URL`에 서버 주소(`wss://.../ws`)를 넣거나, 주소창에 `?server=wss://.../ws`를 붙이세요. 이때 `shared/`와 three.js(`vendor/three/`)도 함께 제공해야 합니다.

## 규칙

| 항목 | 값 |
| --- | --- |
| 생존자 걷기 / 달리기 | 16 km/h / 23 km/h |
| 스태미나 | 10초 달리기, 멈추고 1초 뒤 회복 시작, 0→가득 15초 |
| 술래 이동 | 20 km/h (달리기 없음) |
| 점프 | 술래·생존자 모두 가능. 높이 약 0.6m, 공중 0.5초, 착지하면 바로 다시 뛸 수 있음. 담장·물건은 넘을 수 없음. 공중에서는 덫을 밟지 않음(공격은 그대로 맞음). 생존자는 점프마다 스태미나 1초분 사용(부족하면 불가), 덫에 걸린 동안은 불가 |
| 방망이(오른손) | 쿨타임 1초, 사거리 약 2m, 전방 부채꼴, 벽 너머 불가 |
| 피격 | 3번 맞으면 잡힘(관전 모드), 맞은 뒤 2초 무적. **5명이면 2번** |
| 덫 | 기본 3개, 언제든 설치, 30초마다 1개 회복(최대 3), 밟으면 3초 이동 불가 |
| 덫 가시성 | 술래는 항상, 생존자는 4m 이내에서만 희미하게 보임 |
| 발전기 | 무작위 위치 3개(**5명 이상이면 5개**), 상호작용 키를 꾹 눌러 10초 수리 → 초록불. 손을 떼도 진행도 유지, 여럿이 함께 수리하면 빨라짐 |
| 탈출구 | 발전기를 모두(3개, 5명 이상이면 5개) 켜면 바깥 담장 쪽 무작위 위치에 빛나는 도리이가 생김. 안으로 들어가면 탈출 |
| 승패 | 남은 생존자가 모두 탈출하거나 잡히면 종료. 탈출한 생존자가 1명 이상이면 생존자 승리, 전원 잡히면 술래 승리 |
| 제한 시간 | 7분. 시간이 끝날 때 탈출한 생존자가 1명이라도 있으면 생존자 승리, 아무도 탈출하지 못했으면 술래 승리 |
| 인원 | 2~8명. 인원별 규칙은 아래 표 참고 |

**인원별 규칙** (게임 시작 시 인원 기준)

| 인원 (술래 포함) | 술래 | 발전기 | 생존자 체력 |
| --- | --- | --- | --- |
| 2~4명 | 1명 | 3개 | 3칸 |
| 5명 | 1명 | 5개 | 2칸 |
| 6~8명 | 2명 | 5개 | 3칸 |

술래가 2명이면 각자 직업을 고르고(같은 직업 가능), 서로의 덫을 밟지 않으며 저격수 총알은 동료 술래를 통과합니다. 게임 중 술래 1명이 나가면 남은 술래로 계속하고, 술래가 모두 나가면 생존자 승리입니다.

모든 장애물(담장, 집, 전봇대, 자판기, 트럭, 나무, 발전기 등)은 술래와 생존자 모두 통과할 수 없습니다.

## 맵

대기실에서 **방장이 맵을 고릅니다**: 🎲 랜덤(기본) 또는 시골 마을·폐광산·백룸 중 하나. 다른 사람은 정해진 맵만 볼 수 있고, 고른 맵은 다음 판에도 유지됩니다. 랜덤이면 방장이 게임 시작을 누른 뒤 술래가 직업을 고르는 동안 세 맵 중 하나가 같은 확률로 정해지고, 선택 화면에 모두에게 표시됩니다. 세 맵 모두 크기는 150m×150m입니다. 시골 마을과 폐광산은 배치(골목, 담장, 건물, 발전기·탈출구 후보)가 같은 방식으로 만들어지고 분위기만 다르며, 백룸은 5m 격자의 방들이 문으로 이어진 전용 미로(벽 1.9m, 천장 3.6m)로 판마다 새로 만들어지고 모든 방이 반드시 이어집니다.

| 맵 | 분위기 | 시야 |
| --- | --- | --- |
| 🏘️ 시골 마을 | 해질녘 일본 시골: 블록 담장, 기와집, 논, 신사, 전봇대, 자판기. 탈출구는 빛나는 도리이 | 약 75m |
| ⛏️ 폐광산 | 바위 천장과 종유석이 있는 갱도: 암반 벽, 녹슨 함석 건물, 레일과 침목, 갱도 버팀목, 랜턴, 광차, 권양탑, 출입금지 표지판, 떠다니는 먼지, 헤드램프. 탈출구는 빛이 새어 나오는 갱구 | 약 60m (어둑함, 헤드램프) |
| 🟨 백룸 | 끝없이 이어지는 노란 벽지 사무실 방 미로: 눅눅한 겨자색 카펫, 천장 타일, 깜빡이는 형광등과 웅웅거리는 소리, 기둥이 늘어선 넓은 홀. 탈출구는 하얀 빛이 새어 나오는 초록 EXIT 문 | 약 75m (누런 안개) |

폐광산에는 도로 양쪽에 갱도 버팀목 기둥이 추가로 서 있습니다(지나다닐 수 있는 공간은 마을과 거의 같음). 개발/시험할 때는 `GHOST_MAP=mine npm start`(또는 `village`, `backrooms`)처럼 맵을 고정할 수 있습니다.

## 지도 (생존자 전용)

생존자는 화면 오른쪽 위 🗺️ 버튼(PC는 M 키)으로 맵을 위에서 본 지도를 열고 닫을 수 있습니다. 술래는 지도를 볼 수 없습니다.

- 표시되는 것: **내 위치와 바라보는 방향**, 생존자 누군가가 수리 거리(약 2m)까지 다가가 **찾은 발전기**(모든 생존자에게 공유, 켜지면 초록), **생존자가 잡힌 자리(✖)**, 열린 **탈출구**
- 표시되지 않는 것: 다른 생존자, 아직 아무도 찾지 못한 발전기, 술래
- 지도는 화면을 덮지만 보는 동안에도 움직일 수 있습니다(앞이 잘 안 보여 위험해요)
- 휴대폰에서는 조이스틱으로 움직이는 중에도 다른 손가락으로 🗺️ 버튼을 눌러 지도를 켜고 끌 수 있습니다
- 지도 정보는 서버가 생존자에게만 보냅니다

## 술래 직업

방장이 게임 시작을 누르면 무작위로 술래(6명 이상이면 2명)가 정해지고, 술래는 **15초 안에 각자 직업**을 고릅니다(그동안 생존자는 대기 화면). 시간 안에 고르지 않으면 무작위로 정해지고, 7분 타이머는 직업이 정해진 뒤 시작합니다. 선택 중 술래가 나가면 대기실로 돌아갑니다.

| 직업 | 공격 | 보조 |
| --- | --- | --- |
| 👹 미치광이 | 방망이 근접 공격: 쿨타임 1초, 사거리 약 2m, 1칸 | 덫 3개 (30초마다 1개 충전) |
| 🥷 암살자 | 쿠나이 근접 공격: 쿨타임 1.5초, 사거리 약 2m, 1칸 | 투명화(스킬 키): 15초 동안 생존자에게 완전히 안 보이고 **이동 속도 50% 증가(30km/h)**, 심장 박동도 울리지 않음(서버가 위치 자체를 보내지 않음). 생존자를 맞히면 바로 풀리고 **3.5초간 이동 속도 50% 감소(10km/h)** (시간이 다 돼서 풀리면 감속 없음). 쿨타임 8초는 투명화가 끝난 뒤부터. 투명화 중 내 쿠나이는 반투명. 덫 없음 |
| 🎯 저격수 | 저격총: 쿨타임 2초, 총알은 초속 150m로 날아가며 거리 제한 없음(장애물에 막힘). 조준점으로 항상 정확히 날아감. **30m 안 명중 1칸, 30m 밖 명중 2칸** | 조준 키(누르고 있는 동안 스코프 확대, 이동 속도 절반 10km/h). 덫 없음 |
| ⚓ 선장 | 후크: 사거리 약 2m, 쿨타임 0.5초, 1칸 | 닻 던지기(쿨타임 7.5초): 초속 25m로 최대 20m, 벽에 막힘. 맞은 생존자는 피해 없이 1.5초 동안 선장 앞까지 끌려옴(그동안 조작 불가, 벽에 막히면 멈춤). 선장은 그동안 자유롭게 움직임. **닻이 날아가는 동안에는 선장과 닻 사이 밧줄에 닿은 생존자도 모두 끌려옴**(닻은 계속 날아감, 벽에 가린 밧줄은 무효, 닻이 멈추면 밧줄도 사라짐) |
| 👻 유령 | 할퀴기: 사거리 약 2m, 쿨타임 0.5초, 1칸 (벽 너머는 불가) | 패시브: 담장·벽 통과(집·발전기 등은 막힘, 맵 밖은 불가). 유도탄(쿨타임 7초): 시야 안에서 벽에 가리지 않은 생존자마다 작은 유령이 초속 5m로 5초 동안 벽을 통과해 따라가고 맞으면 1칸. 보이는 생존자가 없어도 쿨타임은 소모 |
| 🎭 살가죽을 뒤집어 쓴 자 | 갈고리: 사거리 약 3m, 쿨타임 1.5초, 1칸 | 변장(지속 시간 없음): 무작위 생존자의 모습·이름표로 보이고 심장 박동이 울리지 않으며 걷기 속도(16km/h)로 움직임. 공격 키를 누르면 명중과 상관없이 바로 풀리고, 그때부터 쿨타임 5초 |
| ⚡ 질주자 | 발차기: 사거리 약 3m, 쿨타임 1초, 1칸 | 패시브: 이동 속도 +10%(22km/h). 질주(쿨타임 15초, 끝난 뒤부터): 누른 순간 보던 방향으로 0.5초 대기 후 1초 동안 30m 돌진. 처음 부딪힌 생존자에게 1칸 주고 멈춤, 벽에 닿아도 멈춤 |

모든 직업의 이동 속도는 20km/h(질주자 22km/h, 저격수 조준 중 10km/h, 암살자 투명화 중 30km/h, 살가죽 변장 중 16km/h)이고, 맞은 생존자는 2초 무적입니다. 5인 규칙(체력 2칸)에서는 30m 밖 저격 한 방에 잡힙니다.

## 조작

**모바일**: 왼쪽 아래 조이스틱으로 이동, 화면 빈 곳을 드래그해 시점 회전.
오른쪽 아래 버튼은 생존자 **달리기**(누르고 있기), 미치광이 **덫**, 암살자 **투명화**, 저격수 **조준**(누르고 있기)입니다. 그 위의 작은 버튼이 **점프**입니다. 가운데에서 오른쪽 버튼은 생존자 **수리**(발전기 근처에서 꾹 누르기), 미치광이·암살자 **공격**, 저격수 **발사**입니다.
손가락마다 역할을 따로 추적하므로 조이스틱으로 이동하는 중에도 공격, 덫, 달리기 버튼이 동시에 눌립니다.

**PC**: 화면을 클릭해 마우스를 고정한 뒤 WASD 이동, 마우스 시점, **스페이스바 점프**, **마우스 좌클릭 기본 공격**(저격수는 발사). **V 마이크 켜기/끄기**. 생존자는 **Shift 달리기**, E를 꾹 눌러 수리, M 지도. 술래는 **E가 스킬**(미치광이 덫, 암살자 투명화, 저격수는 누르고 있는 동안 조준, 선장 닻, 유령 유도탄, 살가죽 변장, 질주자 질주). Esc로 커서 해제. 술래는 화면 아래 가운데에 공격(좌클릭)·스킬(E) 칸이 나와 남은 쿨타임과 덫 개수를 보여 줍니다.

화면 감도는 메인 화면, 대기실, 게임 중의 ⚙ 설정에서 바꿀 수 있습니다.

**자이로스코프 (패드/휴대폰 전용)**: 기기를 좌우·위아래로 돌리면 시점이 따라 움직이고, 화면 드래그와 함께 쓸 수 있습니다. 감도 1.0이면 기기를 돌린 각도만큼 화면이 돕니다.
- ⚙ 설정에서 켜고 끄기, 자이로 감도, **좌우 반전·상하 반전**을 바꿀 수 있습니다(기본: 켜짐). 기본 방향은 좌우·상하 모두 반전되어 있고, 반전 스위치를 켜면 그 축이 한 번 더 뒤집힙니다. 노트북/PC에서는 설정이 보이지 않고 동작하지 않습니다.
- 브라우저 정책상 **https:// 주소(또는 localhost)로 접속해야** 동작합니다.
- iPad/iPhone은 처음 버튼을 누를 때 "동작 및 방향" 접근을 허용해야 합니다.

## 소리

- **배경음악** (음원 파일 없이 브라우저에서 합성, 맵마다 다름)
  - 🏘️ 시골 마을: 밤의 시골. 풀벌레와 새 지저귐, 멀리서 우는 늑대(가끔 다른 늑대가 따라 움), 부엉이, 까마귀, 낮게 깔린 음산한 화음과 바람
  - ⛏️ 폐광산: 숨 막히는 축축한 갱도. 탁하게 울렁이는 저음, 병든 폐처럼 쌕쌕거리며 오르내리는 바람, 메아리치는 물방울, 녹슨 금속 삐걱임, 멀리서 무너지는 돌, 어디선가 들리는 거친 숨소리
  - 🟨 백룸: 오래된 마트 매장 음악. 늘어진 테이프처럼 출렁이고 가끔 음이 틀리거나 템포가 처지는 장난감 피아노와 낡은 오르간, 테이프 잡음. 이따금 "딩동" 뒤에 **AI 음성(브라우저 음성 합성)**으로 가상의 "해피데이 마트" 안내 방송이 나옵니다(밝은 말투에 섬뜩한 내용, 목소리 높낮이가 매번 어긋남). 기기에 한국어 음성이 있으면 한국어로 읽습니다
- **술래가 다가올 때(생존자)**: 가장 가까운 술래가 24m 안으로 들어오면 배경음악이 점점 먹먹해지고 작아지며, 8m 안에서는 거의 심장 박동 소리만 들립니다. 투명한 암살자는 거리 계산에서 빠집니다. 백룸 안내 방송은 술래가 가까우면 시작하지 않고, 코앞까지 오면 끊깁니다. 술래와 관전자는 늘 보통 배경음악입니다.
- ⚙ 설정에서 효과음과 배경음악을 따로 켜고 끌 수 있습니다.

## 음성 채팅 (마이크)

대기실의 **🔇 마이크 끔** 버튼이나 게임 화면 오른쪽 위 🔇 버튼(PC는 **V** 키)으로 마이크를 켜고 끕니다. 마이크를 켜지 않아도 다른 사람 목소리는 들립니다. 처음 켤 때 브라우저가 마이크 권한을 묻고, **https:// 주소(또는 localhost)**에서만 동작합니다. 대기실 목록에서 마이크를 켠 사람 이름 옆에 🎤가 보입니다.

| 상황 | 들리는 방식 |
| --- | --- |
| 대기실 · 술래 직업 선택 · 결과 화면 | 방 안 모두가 같은 크기로 |
| 게임 중 (살아 있는 사람끼리) | 술래·생존자 모두 서로 들림. **2m 안은 최대, 멀어질수록 작아지다가 35m부터 안 들림** |
| 벽·담장·건물 너머 | 거리로 정해진 크기의 70% + 먹먹하게 (벽을 통과하는 유령도 같음) |
| 투명화 중인 암살자 | 살아 있는 생존자에게는 안 들림(동료 술래에게는 들림) |
| 잡힌 사람 · 탈출한 사람 (관전자) | 관전자끼리만 거리 상관없이 대화. 살아 있는 사람과는 서로 안 들림 |

소리 크기는 서버가 사람마다 계산해서 보내고(위치를 숨기는 투명 암살자도 안전), 목소리 자체는 서버를 거치지 않고 WebRTC로 서로 직접 주고받습니다. 공유기/회사망 환경에 따라 직접 연결이 안 되면 `frontend/js/config.js`에서 `window.GHOST_ICE_SERVERS`에 TURN 서버를 넣을 수 있습니다.

## 방

- **방 만들기**: 4자리 참가 코드가 생기고 대기실로 이동합니다. 방장은 👑로 표시됩니다.
- **방 목록**: 대기 중인 공개 방이 실시간으로 보이고, 참가 버튼으로 바로 들어갑니다. 게임 중인 방과 비공개 방은 나오지 않고, 가득 찬 방은 '가득 참'으로 표시됩니다.
- **공개/비공개**: 새 방은 기본 공개입니다. 방장이 대기실에서 🔒 비공개 방을 켜면 목록에서 사라지고 참가 코드로만 들어올 수 있습니다(언제든 다시 공개 가능).
- **코드로 참가**: 코드 4자리를 입력하면 바로 참가합니다. 틀린 코드, 가득 찬 방, 게임 중인 방은 안내가 나옵니다.
- **강퇴**: 방장만 대기실에서 할 수 있습니다(실수 방지를 위해 두 번 눌러 확인).
- 방장이 나가면 다음 사람이 방장이 되고, 게임이 끝나면 같은 대기실로 돌아옵니다.
