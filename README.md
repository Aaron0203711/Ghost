# GHOST · 시골 마을 술래잡기

일본 시골 마을(블록 담장 골목, 기와집, 논, 신사)을 배경으로 한 **1인칭 온라인 비대칭 술래잡기**입니다.
술래 1명과 생존자(최대 4명)가 겨루며, 브라우저만 있으면 휴대폰과 PC에서 함께 플레이할 수 있습니다.

## 실행

```bash
npm run setup   # backend(ws), frontend(three.js) 의존성 설치
npm start       # http://localhost:3000 (PORT 환경변수로 변경)
npm test        # 백엔드 규칙/방/서버 테스트
```

친구와 플레이하려면 서버를 외부에서 접속 가능한 곳(클라우드 서버, 또는 ngrok 같은 터널)에 띄우고 그 주소를 공유하면 됩니다.

## 구조 (백엔드 / 프론트엔드 분리)

```
backend/   Node.js 서버 (권한 서버: 모든 판정은 서버가 결정)
  src/server.js   HTTP + WebSocket(/ws), 프론트엔드 정적 파일 제공
  src/rooms.js    방 만들기 / 4자리 코드 참가 / 강퇴 / 방장 위임 / 시작
  src/game.js     게임 시뮬레이션: 이동 검증, 스태미나, 방망이, 덫, 발전기, 탈출, 승패
  src/mapgen.js   시드 기반 마을 생성, 발전기·시작 위치 배치(도달 가능한 곳만)
  test/           node:test 테스트
frontend/  브라우저 클라이언트 (빌드 단계 없음, three.js)
  index.html, css/style.css
  js/main.js      메인 → 시작하기(방 만들기/참가) → 대기실 → 게임 → 결과
  js/net.js       WebSocket 클라이언트(자동 재연결)
  js/settings.js  화면 감도·효과음 설정 저장
  js/game/        렌더링(world, models, textures), 입력(input), 게임 세션(session), 효과음(audio)
shared/    양쪽이 함께 쓰는 규칙 상수(constants.js)와 충돌 처리(collision.js)
```

프론트엔드를 다른 곳(정적 호스팅)에 따로 올릴 때는 `frontend/js/config.js`의 `GHOST_SERVER_URL`에 서버 주소(`wss://.../ws`)를 넣거나, 주소창에 `?server=wss://.../ws`를 붙이세요. 이때 `shared/`와 three.js(`vendor/three/`)도 함께 제공해야 합니다.

## 규칙

| 항목 | 값 |
| --- | --- |
| 생존자 걷기 / 달리기 | 16 km/h / 23 km/h |
| 스태미나 | 10초 달리기, 멈추고 1초 뒤 회복 시작, 0→가득 15초 |
| 술래 이동 | 20 km/h (달리기 없음) |
| 방망이(오른손) | 쿨타임 1초, 사거리 약 2m, 전방 부채꼴, 벽 너머 불가 |
| 피격 | 3번 맞으면 잡힘(관전 모드), 맞은 뒤 2초 무적. **5명이면 2번** |
| 덫 | 기본 3개, 언제든 설치, 30초마다 1개 회복(최대 3), 밟으면 3초 이동 불가 |
| 덫 가시성 | 술래는 항상, 생존자는 4m 이내에서만 희미하게 보임 |
| 발전기 | 무작위 위치 3개(**5명이면 5개**), 상호작용 키를 꾹 눌러 10초 수리 → 초록불. 손을 떼도 진행도 유지, 여럿이 함께 수리하면 빨라짐 |
| 탈출구 | 발전기를 모두(3개, 5명이면 5개) 켜면 바깥 담장 쪽 무작위 위치에 빛나는 도리이가 생김. 안으로 들어가면 탈출 |
| 승패 | 남은 생존자가 모두 탈출하거나 잡히면 종료. 탈출한 생존자가 1명 이상이면 생존자 승리, 전원 잡히면 술래 승리 |
| 제한 시간 | 7분. 시간이 끝날 때 탈출한 생존자가 1명이라도 있으면 생존자 승리, 아무도 탈출하지 못했으면 술래 승리 |
| 인원 | 2~5명, 시작 시 무작위 1명이 술래. 5명(술래 포함)이 모이면 5인 규칙: 발전기 5개 + 생존자 체력 2칸 |

모든 장애물(담장, 집, 전봇대, 자판기, 트럭, 나무, 발전기 등)은 술래와 생존자 모두 통과할 수 없습니다.

## 조작

**모바일**: 왼쪽 아래 조이스틱으로 이동, 화면 빈 곳을 드래그해 시점 회전.
오른쪽 아래 버튼은 생존자에게는 **달리기**(누르고 있기), 술래에게는 **덫**입니다. 가운데에서 오른쪽 버튼은 술래에게는 **공격**, 생존자에게는 **수리**(발전기 근처에서 꾹 누르기)입니다.
손가락마다 역할을 따로 추적하므로 조이스틱으로 이동하는 중에도 공격, 덫, 달리기 버튼이 동시에 눌립니다.

**PC**: 화면을 클릭해 마우스를 고정한 뒤, WASD 이동, 마우스 시점, Shift 달리기, E 수리(꾹), 클릭/Space 공격, Q/우클릭 덫, Esc 커서 해제.

화면 감도는 메인 화면, 대기실, 게임 중의 ⚙ 설정에서 바꿀 수 있습니다.

**자이로스코프 (패드/휴대폰 전용)**: 기기를 좌우·위아래로 돌리면 시점이 따라 움직이고, 화면 드래그와 함께 쓸 수 있습니다. 감도 1.0이면 기기를 돌린 각도만큼 화면이 돕니다.
- ⚙ 설정에서 켜고 끄기와 자이로 감도를 바꿀 수 있습니다(기본: 켜짐). 노트북/PC에서는 설정이 보이지 않고 동작하지 않습니다.
- 브라우저 정책상 **https:// 주소(또는 localhost)로 접속해야** 동작합니다.
- iPad/iPhone은 처음 버튼을 누를 때 "동작 및 방향" 접근을 허용해야 합니다.

## 방

- **방 만들기**: 4자리 참가 코드가 생기고 대기실로 이동합니다. 방장은 👑로 표시됩니다.
- **방 참가**: 코드 4자리를 입력하면 바로 참가합니다. 틀린 코드, 가득 찬 방, 게임 중인 방은 안내가 나옵니다.
- **강퇴**: 방장만 대기실에서 할 수 있습니다(실수 방지를 위해 두 번 눌러 확인).
- 방장이 나가면 다음 사람이 방장이 되고, 게임이 끝나면 같은 대기실로 돌아옵니다.
